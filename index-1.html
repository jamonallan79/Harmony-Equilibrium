FROM IDEA TO RELEASE

Create it in CodeForge. Release it through Harmony Equilibrium.

CodeForge is the mobile creation and packaging environment. Harmony Equilibrium is the public ecosystem for presenting, publishing and selling finished work. Together they form one continuous path from the first line of code to a customer-ready Android application.

HE

    ACTION: RUN ANALYZE

    SPELL

    ACTION: RUN DESCRIBE

    ACTION: RUN NOUNS

    ADVERBS

    ADVERBS highlights words that modify actions or descriptions. Sometimes an adverb is useful; sometimes one stronger verb is cleaner than an adverb plus a weak verb.

    ACTION: RUN ADVERBS
  10. 10

    REPETITION

    ACTION: RUN REPEAT

    FLOW

    FLOW reviews sentence length, passive wording and dialogue or rhythm notes. It helps spot writing that feels cramped, repetitive or difficult to follow.

    ACTION: RUN FLOW
